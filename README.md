# 🤖 AI for Testers

A hands-on learning journey focused on applying Artificial Intelligence to Software Quality Engineering.

## 🎯 Goal

Build practical AI-powered testing solutions while combining modern AI engineering with my existing experience in test automation, API testing, mobile testing, and quality engineering.

## 🗺️ Learning Roadmap

```text

   ↓

   ↓

   ↓
RAG
   ↓

   ↓

   ↓

```

## 📚 Topics

### 01 — Python

Python fundamentals required for AI engineering and test automation.

### 02 — LLM

LLM fundamentals, prompting, structured outputs, APIs, and practical experiments.

### 03 — AI Testing

Testing LLM applications for accuracy, relevance, hallucination, robustness, security, and regression.

### 04 — RAG

Retrieval-Augmented Generation and its application to Quality Engineering.

### 05 — AI Agents

Building AI systems that can reason through tasks and use tools.

### 06 — AI Automation

Combining AI with Selenium, API automation, and test engineering workflows.

## 📈 Philosophy

Learn → Build → Test → Break → Fix → Document → Repeat

This repository is intentionally hands-on. The goal is not just to learn AI concepts, but to understand how they can be engineered and tested in real-world Quality Engineering workflows.
